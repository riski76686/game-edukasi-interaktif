📖 Cara Menempelkan Game Agar Siap Digunakan

🌐 1. Tempelkan di Google Sites (Paling Mudah & Gratis 100%)

Jika sekolah Anda memiliki akun Google Workspace, buka sites.google.com, buat halaman portofolio, klik menu Sematkan (Embed) di panel kanan, lalu pilih Dengan URL dan masukkan link Apps Script Anda. Game akan tampil penuh di halaman web sekolah!

💻 2. Gunakan Portal HTML Ini Sebagai Beranda

Anda bisa menyimpan file portfolio.html ini di komputer, membukanya di browser apa saja, dan menambahkan tautan game sebanyak yang Anda mau. Semua data game yang Anda tambahkan otomatis tersimpan di peramban Anda.

🚀 3. Publikasikan Sebagai Web Gratis (GitHub Pages / Netlify)

Cukup buat repositori di GitHub, unggah file ini dengan nama index.html, lalu aktifkan fitur GitHub Pages. Anda akan langsung memiliki alamat web portofolio profesional pribadi (misal: namaanda.github.io).

Kode Semat HTML (Iframe):
<iframe src="URL_GAME_ANDA" width="100%" height="700px" style="border:none; border-radius:16px;" allowfullscreen></iframe>
